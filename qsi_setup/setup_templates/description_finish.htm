Q4WIN10 Window Decoration has been successfully installed!

The Q4WIN10 window decoration is now installed and ready to be activated on your Trinity desktop.

How to activate Q4WIN10:

  1. Open the Trinity Control Center (or Q4OS Control Centre).
  2. Navigate to Appearance & Themes → Window Decorations.
  3. Select Q4WIN10 from the decoration list.
  4. Click Configure [Q4WIN10]... if you want to customize Dark Mode or Win11 Mode, then click Apply.

Tip: Matches seamlessly with the Q4Win10 Widget Style for a unified Windows 10/11 look.
