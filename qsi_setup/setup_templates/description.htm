Q4WIN10 Window Decoration for Trinity Desktop (TDE)

Q4WIN10 is a modern, lightweight, and flat Windows 10 & 11 style window decoration plugin for the Trinity Desktop Environment (TDE / Q4OS).

Key Features:

  • Windows 10 & 11 Aesthetics: Flat titlebar buttons or modern rounded Win11 buttons with smooth hover transitions.
  • Deep Dark Mode Support: Configurable high-contrast icons and color adaptation for dark desktop themes.
  • Context-Aware Border Color: Seamless integration with Q4WIN10 widget style to harmonize window borders with the application menubar.
  • Dedicated Configuration Panel: Easily toggle Dark Mode and Windows 11 style directly in the TDE Control Center.
  • Ultra-Lightweight & Fast: Hand-optimized freestanding C++ / TQt3 codebase with zero background memory footprint.
  • Universal Compatibility: Fully compatible with all TDE R14.1.x versions (R14.1.0 to R14.1.6+).
